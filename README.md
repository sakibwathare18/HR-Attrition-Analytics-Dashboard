# HR Attrition Analytics Dashboard

## Project Overview
This project analyzes employee attrition trends using Power BI, Excel, and SQL.

The dashboard helps identify factors affecting employee turnover such as:
- Department
- Salary
- Age Group
- Overtime
- Job Role

---

## Tools Used
- Power BI
- Excel
- SQL

---

## Key KPIs
- Total Employees
- Attrition Count
- Attrition Rate
- Average Salary

---

## Key Insights
- R&D department has highest attrition
- Employees working overtime are more likely to leave
- Employees with low salary show higher attrition
- Age group 26–35 has maximum employee exits
